# CellCog Multimodal Sub-Agent Skill

## Overview

The `cellcog-multimodal` skill empowers Brain Harness agents to autonomously orchestrate any-to-any cross-modality delegations via CellCog.

Supported output modalities include:

- **3D Assets**: Text-to-3D and image-to-3D generating `.GLB` assets.
- **Cinematic Video**: 4K landscape trailers, 9:16 vertical short-form reels, and long-form video.
- **Audio & Music**: Multi-host podcasts, narration, and instrumental/vocal tracks.
- **Documents & Presentations**: Executive PDF reports, multi-tab Excel sheets (`.XLSX`), and slide decks.
- **Deep Research**: Citation-backed multi-source intelligence reports (#1 on DeepResearch Bench).
