# Ontological Engineering Coach — Companion Summary Card

## Stage Progression Table

| Stage | Core Responsibility | Completion Gate |
|---|---|---|
| **1. Competency Scoping & Boundary Definition** | Formulate explicit natural-language competency questions defining the questions the knowledge model must answer. | `Exhaustive list of verifiable competency questions agreed upon and documented.` |
| **2. Taxonomy & Class Hierarchy Construction** | Draft the core subsumption hierarchy and relationship predicates satisfying audited competency queries. | `Directed Acyclic Graph (DAG) of class hierarchies verified free of cycles.` |
| **3. Gruber 5-Axis Quality Audit** | Evaluate candidate schema against Clarity, Coherence, Extendibility, Minimal Bias, and Minimal Commitment. | `Scored evaluation matrix with zero critical violations across all 5 criteria.` |
| **4. Competency Verification & Query Validation** | Translate competency questions into SPARQL queries and verify expected result sets against sample instance graphs. | `100% of competency questions execute with non-empty, semantically correct answer sets.` |
| **5. Modularization & Lineage Documentation** | Partition ontology into composable modules and author persistent documentation and CARD summary. | `Versioned ontology artifact with metadata annotations and schema diagrams published.` |

---

## Vocabulary & Levers

- **Competency Question**: Natural language query defining the questions the model must answer.
- **Minimal Commitment**: Specifying only what is strictly necessary to satisfy target tasks.
- **Subsumption Transitivity**: Formal verification that subclass members strictly belong to the superclass.
- **Encoding Bias**: Erroneous dependency on specific syntactic quirks of a serialization format.

---

## Mandatory Invariants Checklist

- [ ] Competency questions verified before asserting class hierarchies
- [ ] Gruber's Minimal Ontological Commitment enforced (zero speculative classes)
- [ ] Reasoner consistency check passes with zero logical contradictions
- [ ] Representation encoding bias eliminated across serializations
