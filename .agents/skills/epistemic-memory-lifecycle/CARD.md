## Vocabulary & Levers

- **Plugin**: An acquired capability — foreign code admitted through ingestion and isolated in sandboxes.
- **Skill**: A reusable procedure for applying capability — deterministic stage progressions with checkable completion gates.
- **Knowledge Item (KI)**: An evidence-linked claim or learned pattern — dual-file (operational `.md` + epistemic `metadata.json`).
- **Workflow**: A governed composition of skills, tools, and human checkpoints executing an end-to-end mission.
- **Constitutional Layer**: Non-learning core (sandboxes, allowlists, human gates) permanently immune to agent reflection mutation.
- **Epistemic Horizon**: Strict boundary defining what an agent role knows versus what it does not know.
- **Isnad Lineage**: Unbroken chain of custody linking an assertion back to primary code, commits, or deterministic test results.

## Mandatory Invariants Checklist

- [ ] Every candidate assertion must cite at least one empirical primary source node with file path and line slice.
- [ ] No claim lacking empirical evidence may be marked with status VERIFIED; ungrounded claims must be isolated as HYPOTHESIS.
- [ ] The Constitutional Layer (sandboxes, tool allowlists, human approval gates) must NEVER be altered by agent reflection.
- [ ] Multi-model evaluation must test candidate patterns against held-out tasks rather than treating model agreement as proof.
- [ ] Dual-file KI format (operational narrative markdown + JSON metadata) is mandatory before vault admission.
- [ ] The Mandatory Governance Checkpoint must be observed before advancing any claim from EVIDENCE-VERIFIED to ACTIVE.
- [ ] The 4-Pillar Ship of Theseus continuity audit (Purpose, Governance, Evaluation, Accountability) must pass before final commit.
