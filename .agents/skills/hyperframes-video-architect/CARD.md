## Stage Progression Table

| Stage | Core Responsibility | Primary Artifact | Completion Gate |
| --- | --- | --- | --- |
| **1. Scene Decomposition** | Decompose video narrative into scenes | `scene_manifest.json` | Valid duration and transitions |
| **2. Template Composition** | Build Tailwind/GSAP HTML animation stage | `scene_template.html` | Browser-compatible stage markup |
| **3. Subprocess Render** | Execute JSON-RPC render or simulated fallback | `output_video.mp4` | Artifact created with frame count |

## Core Capabilities
- Scene-by-scene programmatic motion graphics composition.
- Trajectory playback and animated Git PR diff video rendering.
- Headless simulation fallback for headless CI testing.

## Mandatory Invariants Checklist
- [ ] Every video request contains at least one valid `VideoScene` with duration $> 0$.
- [ ] Subprocess execution adheres to Rule 14 pipe drainage and Rule 56 loopback preservation.
- [ ] Frontmatter description enforces action verbs and strict negative boundaries.
- [ ] Standalone scene previews validate HTML structure without external browser requirements.
