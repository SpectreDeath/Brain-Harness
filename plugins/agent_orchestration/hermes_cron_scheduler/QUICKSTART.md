# Quick Start Guide: `domain.hermes_cron_scheduler`

## 🎯 When to Use
Use this plugin for natural language background cron scheduling, incident inspection, and catalog management.

## 🛠️ Available Entrypoints
- `schedule_natural_cron(schedule_expr, prompt_action, target_channel)`
- `list_cron_jobs(status_filter)`
- `inspect_cron_incidents(job_id, limit)`
- `manage_blueprint_catalog(action, blueprint_id)`
