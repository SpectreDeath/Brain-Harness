# Problem: Decompose and Step Through a DAG Plan

## Objective

Decompose a goal with 3 tasks (`task_a`, `task_b`, `task_c` where `c` depends on `a` and `b`), retrieve the unblocked milestone, and transition tasks to completion.

## Tasks

1. Define subtasks with parallel dependencies.
2. Query next milestones before and after completing prerequisite steps.
