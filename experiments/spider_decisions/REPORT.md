## 2. Deep-Dive Findings Across All 12 Use Cases

### 2.1 Data Hygiene & Bridge Match Strength (Phases 0, 1, 2)
- **Snapshot Reliability (`Phase 0`):** All 7 serialized JSON models matched live scans with `100%` identical entity counts, assertion counts, and triple sets ([roundtrip_check.json](results/p00/roundtrip_check.json)), cutting repeated audit runs from ~26 s (`grm`) to milliseconds.
- **False-Bridge Elimination (`Phase 1`):** Tracking `"structured"` vs `"tag"` match strength, rejecting `"tag"` matches on generic/short (`<= 4`-char) unit names, ignoring prose `source_target` strings, and pruning intermediate generic subpaths removed `6/7` pre-fix false bridges—including both target defects (`airllm_plus/runtime` and `grm/rpc`) plus `airllm/data`, `airllm/eval`, and `gvisor/tools`—reducing FP rate from `0.1750` to `0.0588` at `0.9697` recall and `10/10` regression pass ([metrics_after.json](results/p01/metrics_after.json), [summary.md](results/p01/summary.md)). Two edge cases remain where external repo names collide with sub-unit names (`gvisor/shim` → `ki_shim_bounded_session_and_layered_skill_loader`, swapped `gvisor/governance` → `ki_vercel_ui_sdk_expert_scope_governance`).
- **Vault Hygiene (`Phase 2`):** Out of `377` vault KIs, `78` remain `isnad_verified=False`, led by `ki_solla_dmbok_governance_decision_rights` and `ki_njoku_uncertainty_aware_systems` (`in_degree=2`) ([unverified_priority.md](results/p02/unverified_priority.md)). Duplicate screening surfaced `12` overlapping `ki_self_20260826_*`–`20260908_*` pairs with zero explicit `same_domain`/`related_to` edges ([duplicate_review_sheet.md](results/p02/duplicate_review_sheet.md)).

### 2.2 Portfolio Blind Spots, Target Ranking & Entropy Questions (Phases 3, 4, 5)
- **Domain Blind Spots (`Phase 3`):** Counting non-generic repo units against mapped vault KIs (verified 100% against `project_entities()`) exposed stark skew ([blind_spots.md](results/p03/blind_spots.md)): `vision_and_3d_project` (`gap=158.0`, `158` units / `0` KIs), `nlp_and_llm_project` (`gap=77.0`, `154` / `1` KI), and `rl_and_control_project` (`gap=58.0`, `58` / `0` KIs) vs saturated `agent_orchestration_project` (`gap=0.05`, `122` KIs).
- **Composite Learning Target Ranking (`Phase 4`):** Across `127` tested arXiv-backed unlearned `grm` subprojects, the spider composite score picked `poem`, `tunas`, `t5_closed_book_qa`, `saccader`, and `tf3d`, covering `709.00` total domain gap (`2` domains)—more than double `human_shortlists` (`350.12`, `5` distinct domains: `dp_sgd_clipping`, `smart_eval`, `perturbations`, `norml`, `psycholab`), `largest_5` (`297.12`), `random_5` (`288.12`), and `most_tests_5` (`281.38`). Stratified 5-domain shortlists raised human gap coverage above Run 1's unstratified random proxy (`191.25`) and all single-axis baselines, while achieving `overlap@5=1` with `random_5` (`dp_sgd_clipping`) and `0` with `spider_composite`, `largest_5`, and `most_tests_5` ([comparison.md](results/p04/comparison.md), [human_picks.json](results/p04/human_picks.json)).
- **Entropy Question Selection (`Phase 5`):** Narrowing the top-20 targets via `classification_score` required `1.80` questions on average (worst case `2`) vs `3.65` (worst case `7`) for random attribute order, uniquely identifying `20/20` (`100.0%`) targets under both policies ([results/p05/summary.md](results/p05/summary.md)).

### 2.3 Code-Change Retrieval & Cited Design Arbitration (Phases 6, 7)
- **Graph Retrieval Sparsity (`Phase 6`):** Strict `references_code` lookup achieved high precision on `vector_index` (`1.00/1.00`) and gained recall via hop-1 `related_to` on `uncertainty_guard` (`0.25 -> 0.50` at `1.00` precision), **but** averaged only `0.3333` F1 at `hop1` vs `0.8769` for full-text substring grep ([results/p06/summary.md](results/p06/summary.md)). `6/13` gold KIs have zero `references_code` edges, while existing links use non-canonical objects (`src_harness_services_uncertainty_guard_py`, `src_harness_services_deep_auditor___init___py`) or `applicable_to` predicates; `12` backfill edges were proposed in [edge_backfill_proposal.md](results/p06/edge_backfill_proposal.md).
- **Grounded Design Memos (`Phase 7`):** Evidence dossiers yielded actionable architectural specs with explicit verification accounting: [memo_q1.md](results/p07/memo_q1.md) cited `11` valid KIs (`87.5%` verified claims, `2` conflicts, `2` gaps — flagging unverified `ki_self_20260922_02` and `ki-hf-datasets-arrow-streaming`), and [memo_q2.md](results/p07/memo_q2.md) cited `4` valid KIs (`100.0%` verified claims, `2` conflicts, `1` gap — flagging the missed unverified `ki_njoku_uncertainty_aware_systems`) ([memo_scores.json](results/p07/memo_scores.json)).

### 2.4 Triage Classifier, Refactor Ordering, Skill Routing & Grounded Voting (Phases 8, 9, 10, 11)
- **Syntax Classifier Limits (`Phase 8`):** A syntactic heuristic over `primary_language`, `has_tests`, `packaging`, `has_readme`, and `has_arxiv` scored only `2/14` (`0.1429`) ([results/p08/summary.md](results/p08/summary.md)): TypeScript/Go/docs repos (`adk-web`, `magika`, `earthengine-api`, `styleguide`, `adk-docs`) became plugins (`7/10` false misses), `harness2`/`tunix-main`/`perfetto` lost `has_tests` under the 60-file portfolio cap, and Python+tested `airllm`/`grm` were intentionally kept `ki_only`.
- **Refactor Order & Hidden Coupling (`Phase 9`):** Ordering `src/harness` (`commands, ui, mcp, agent, creator, bridges, services, plugins, ingestion, kernel, events`) surfaced `ui -> commands -> ui` (pinpointed to `src/harness/ui/server/routes/skills.py`), an 11-unit Tarjan SCC (`blast_radius=10`) caused by `src/harness/kernel/runtime/` (`defaults.py`, `factory.py`, `services.py`, `tools.py`, `plugins.py`) importing across all feature packages, `6/10` overlap with `ki-file-size-hotspots` & `ki-deepening-cycle-history`, and `2` upward leaks in `services/` (`skill_graph/joint_query.py -> commands`, `storage/vault_retrieval.py -> creator`) ([results/p09/summary.md](results/p09/summary.md), [human_review.md](results/p09/human_review.md)).
- **Skill Routing (`Phase 10`):** Existing `BuiltinSkillRegistryService.route_intent` scored `19/20` (`95.0%`) at both `Hit@1` and `Hit@3` across `114` workspace skills (missing only task #2 `ontology-spider -> research`). Naive Spider routing (`10.0% Hit@1`, `20.0% Hit@3`) and unweighted `+1`-per-KI Hybrid re-ranking (`65.0% Hit@1`, `95.0% Hit@3`) degraded precision because broad tags (`agent`, `memory`, `architecture`) act as high-degree hub attractors toward `ai-agent-engineer`, `epistemic-memory-lifecycle`, and `architecture-deepening-workflow` ([results/p10/summary.md](results/p10/summary.md)).
- **Evidence-Grounded Swarm Voting (`Phase 11`):** Weighting agent vote confidence by vault `isnad_verified` status (`1.0` verified / `0.6` unverified / `0.4` none) before `ConsensusEngine.evaluate_cisc_consensus(..., normalization='softmax', temperature=2.5)` lifted accuracy from `2/12` (`16.7%`) to `11/12` (`91.7%`), flipping `9` disputes toward verified-KI choices with `0` regressions while keeping a 4-to-1 overwhelming plurality bounded on stress dispute #12 ([results/p11/summary.md](results/p11/summary.md)).
